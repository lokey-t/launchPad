# LaunchPad 轻量应用启动器

一个简约扁平化的 Windows 应用分类启动器：全局快捷键呼出、顶部 Tab 分类、Launchpad 式图标网格、拖拽排序与合并文件夹、拖入文件即添加应用、开机自启。

## 快速开始

- **可执行文件**：`bin\Release\net8.0-windows\LaunchPad.exe`
- 运行后按 **Ctrl+Space** 呼出 / 隐藏主界面（可在设置中改绑快捷键）
- 首次启动自带分类（办公 / 系统工具 / 未分类），可自行删改

## 功能

| 功能 | 操作方式 |
| --- | --- |
| 呼出/隐藏 | 全局快捷键 Ctrl+Space（任意程序下可用，再次按快捷键可关闭） |
| 添加应用 | 把 `.exe` / `.lnk` / `.bat` 等文件或快捷方式**直接拖进窗口**；已在启动器中的文件会提示「未添加：已在启动器中」 |
| 分类管理 | 顶栏「+」新建分类；设置 → 应用管理 中重命名 / 删除分类 |
| 拖动排序 | 图标实时让位并显示半透明占位；松手后提交排序，Esc 取消并恢复原位置 |
| 合并文件夹 | 把一个图标拖到另一个图标上，自动创建文件夹（iOS 桌面逻辑） |
| 移入文件夹 | 拖到文件夹中央直接松手可放入；悬停 2 秒自动展开，可按插入线选择内部位置 |
| 删除应用 | 右键应用 →「从启动器移除」；右键文件夹 →「删除文件夹（内部应用放回分类）」 |
| 文件夹开合 | 单击文件夹：缩略图**原地变形成居中弹窗**（同一套代码两个状态，非线性缓动）；点击弹窗外 / Esc / 切分类 / 失焦关闭 |
| 文件夹内容 | 未打开时显示 2×2 缩略图，**超过 4 个显示数量角标**（角标位于第 4 格位置，≤4 个不显示）；打开后列数随数量展开（2→6 列自适应），超过 6 列可上下滚动 |
| 文件夹内操作 | 子应用拖出边界后文件夹自动收起，继续拖到网格或其他分类再松手；内部仍支持拖动排序和标题重命名 |
| 启动应用 | 默认单击启动 |
| 搜索 | 顶栏搜索框按名称过滤 |
| 隐藏模式 | 设置中可选：启动应用后自动隐藏 / 焦点离开时自动隐藏 / 再次按快捷键隐藏 |
| 主题 | 设置中切换 浅色 / 深色 / 跟随系统 |
| 动画模式 | 设置 → 外观与动效：关闭 / 快速 / 均衡 / 优化，统一控制窗口、页面、文件夹与拖动动画 |
| 图标大小 | 小 / 中 / 大三档 |
| 弹窗位置 | 屏幕居中 / 跟随鼠标（切换后立即生效） |
| 开机自启 | 设置 → 常规 中打开「开机自启」（写入 HKCU\...\Run） |
| 托盘 | 关闭主窗最小化到托盘，托盘菜单可显示 / 设置 / 退出 |

## 交互细节

- 点击分类时使用滑动与淡入过渡；拖动条目或外部文件到分类标签，悬停后自动切换。设置 → 常规与启动 → 拖拽悬停，可独立设置文件夹展开和分类切换时间（0.3–5 秒连续调节，默认 2 秒）。
- 悬停浏览不会改变条目归属，只有在有效位置松手才提交；拖到窗口外松手或按 Esc 取消内部拖动。
- 拖动到滚动区域上下边缘可自动滚动，外部多文件导入保持输入顺序。

- 主窗口、设置窗口的空白处可按住拖动调整位置；新建分类弹窗点击遮罩空白处关闭。
- 文件右键菜单支持快速修改分类、修改显示名称、选择自定义图标及恢复默认图标；改名不修改磁盘文件名。
- 拖动排序保留图标让位与半透明占位，不再显示蓝色插入指示栏。
- 重复导入使用 Toast 提示已有文件及所属分类，未分类条目省略分类说明。
- 应用内禁用 Tab 焦点切换和 Alt 按键提示，不改变 Windows 系统设置。
- 拖入应用时顶部显示悬浮提示条，不遮挡图标网格
- 文件夹开合采用 iOS 风格过渡：从原格子缩放、平移至居中卡片，同一组真实图标连续移动、缩放，额外图标通过卡片裁剪边界显露，无截图叠加或交叉淡化，背景同步渐暗；展开约 380ms、收起约 290ms。动画期间保持布局和列数不变，避免反复重排；支持展开中途关闭，并遵循系统动画开关。
- 「全部」视图同样支持拖动排序、建文件夹、跨分类移动

- 新建分类、重命名与确认弹窗采用统一卡片样式与开合过渡。
- 再次运行软件时会提示已运行，并显示配置中实际保存的呼出快捷键。

## 配置文件

`%AppData%\LaunchPad\config.json`（JSON，可直接编辑；修改后重启生效）

- 分类结构：`Categories[]` → 每项含 `Name` 与 `Entries[]`
- 条目两种：`"kind": "app"`（应用）与 `"kind": "folder"`（文件夹，内含 `Items[]`）
- 热键：`HotkeyModifiers`（2=Ctrl, 1=Alt, 8=Win, 4=Shift，可组合相加）、`HotkeyKey`（虚拟键码，32=Space）
- 启动方式：`LaunchMode` = `"Single"`（单击）
- 动画模式：`AnimationMode` = `"Off"` / `"Fast"` / `"Balanced"` / `"Optimized"`（默认均衡）
- 悬停秒数：`FolderHoverSeconds` / `CategoryHoverSeconds`（默认 2，范围 0.3–5，连续调节）
- 自定义图标：应用条目的 `CustomIconPath`；选中的图片复制保存到 `%AppData%\LaunchPad\Icons`。
- 隐藏模式：`HideOnFocusLost`（失焦隐藏）、`HideAfterLaunch`（启动应用后隐藏）

## 源码结构

技术栈：C# / WPF（.NET 8，`net8.0-windows`）+ WinForms 托盘，零第三方依赖。

`MainWindow` 按职责拆分为 6 个 partial 文件：

| 文件 | 职责 |
| --- | --- |
| `MainWindow.xaml.cs` | 字段/属性/配置加载/核心 UI 事件/搜索/文件夹管理（移除、重命名、启动）/外部拖入与增删 |
| `MainWindow.FolderAnim.cs` | 文件夹开合动画全套（打开/关闭/缓动/格子几何缓存/标题点击） |
| `MainWindow.FolderDrag.cs` | 文件夹内拖拽排序全套（按下/移动/抬起/让位动画/刷新网格） |
| `MainWindow.DragDrop.cs` | 拖拽视觉、命中判断及网格几何辅助 |
| `MainWindow.DragSession.cs` | 连续拖拽、分类/文件夹悬停、插入位置提示、松手提交与取消 |
| `MainWindow.ItemActions.cs` | 条目右键菜单、分类移动、显示名称与自定义图标、Toast |

其他：`SettingsWindow`（设置）、`Models`（配置模型）、`Services`（热键 / 图标提取 / 启动 / 自启 / 配置）、`App.xaml.cs`（托盘 / 单实例 / 启动装配）。

## 开发构建

```powershell
& "$env:USERPROFILE\.dotnet\dotnet.exe" build LaunchPad.csproj -c Release
```

构建前若 exe 正在运行（文件被锁定），先 `taskkill /F /IM LaunchPad.exe`。

## 备份说明

历史版本备份存放在仓库根目录 `backups\` 下：

- `MainWindow.xaml.cs.bak_*` / `MainWindow.xaml.bak_*`：各迭代阶段源码快照（`bak_pre_refactor` = 拆分重构前的合并版，可整文件回滚）
- `config_user_now*.json`：各阶段用户配置备份（`config_user_now7.json` 为早期权威备份；`config_user_current.json` 为最新运行状态快照）
- `devartifacts\`：历史开发调试产物（测试截图、日志、对比文本），仅供回溯
