# LaunchPad v0.95

## 中文

- 主题中心：六套预设、自定义配色、图片 / GIF / 视频背景，全局与分类独立设置。
- 连续拖拽与文件夹动画、分类悬停切换、分类拖动排序。
- 两个独立悬停时间滑条，在 0.5、1、2 秒附近轻微吸附。
- 细圆角滚动条和滚轮缓动，支持四种动画模式。
- 分类快捷键集中管理，修改和删除并排；主页主题按钮可隐藏。
- 自定义条目名称、图标及分类，重复导入 Toast 提示。
- 中英文 README，版本号更新为 0.95。

推荐下载 `LaunchPad-v0.95-win-x64.zip`（自带运行时）；精简包 `LaunchPad-v0.95-win-x64-framework-dependent.zip` 需要 .NET 8 Desktop Runtime（x64）。升级前从托盘退出旧版本。配置保留在 `%AppData%/LaunchPad`。

## English

- Theme Center: six presets, custom colors, image / GIF / video backgrounds, and global or per-category settings.
- Continuous drag and drop, folder transitions, hover category switching, and category reordering.
- Independent hover delays with gentle magnetic stops at 0.5, 1, and 2 seconds.
- Slim rounded scrollbars and smooth wheel scrolling with four motion modes.
- Centralized category shortcuts with adjacent Edit and Delete actions; optional main-window theme button.
- Custom entry names, icons, and categories, plus duplicate-import Toast notifications.
- Chinese and English READMEs; version updated to 0.95.

Recommended: `LaunchPad-v0.95-win-x64.zip` includes the runtime. The smaller `LaunchPad-v0.95-win-x64-framework-dependent.zip` requires .NET 8 Desktop Runtime (x64). Exit the old tray instance before upgrading. Settings remain in `%AppData%/LaunchPad`.

## 验证 / Validation

Release 构建与独立 WPF 交互回归检查通过，测试未修改用户配置。
Release build and isolated WPF interaction regression checks passed without modifying user settings.
